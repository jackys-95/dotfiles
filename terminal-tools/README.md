# Terminal tools

This directory contains installation and usage guides for terminal applications that need extra setup but are not tracked here as full configuration trees.

| Tool | Guide | Purpose |
|---|---|---|
| mdterm | [mdterm/README.md](mdterm/README.md) | Markdown viewing in Rex, including image and Mermaid behavior |

Add another tool here when it needs its own reproducible setup notes.

## Candidate: markdown-on-kitty

[markdown-on-kitty](https://github.com/H1rla/markdown-on-kitty) is an option if zoomable Mermaid diagrams in a Markdown preview become important. It has not been installed or tested in Rex.

Before adopting it, audit the codebase and dependency stack, verify repository activity, and estimate the ongoing maintenance burden. Initial activity appears limited, and the breadth of its dependencies makes maintenance a concern. A one-off trial is still reasonable if it works without follow-up fixes.
